# hongchu-sign

西安石油大学自动签到 Android App — 简洁、轻量、后台定时执行。

## 为什么有这个项目

此前我维护了一个网页版托管服务 [xsyusign.hongchu.xyz](https://xsyusign.hongchu.xyz)，用户提交学号密码即可全自动签到。但该服务依赖我个人服务器，且账户需交给我保管。

`hongchu.xyz` 域名到期后网页版将停止运营，因此开发了本 App 作为永久替代方案。

## 网页版 vs 安卓版

| | 网页版 | 安卓版 |
|---|---|---|
| 自动签到 | ✅ 全自动 | ✅ 定时执行 |
| 账户存储 | ⚠ 服务器端 | ✅ 仅存本地 |
| 隐私安全 | ⚠ 需信任托管方 | ✅ 数据不出手机 |
| 配置难度 | 零配置 | 需设置签到日/时间 |
| 运行条件 | 无 | 手机需开机 |
| 服务期限 | 域名到期即停 | 永久可用 |

## 功能

- **用户管理** — 增删改查，AES 本地加密存储密码
- **定时签到** — WorkManager 后台巡检，每 15 分钟检查一次
- **手动签到** — 一键全量签到，无视时间窗口限制
- **日历计划** — 自由选择签到日 + 时间窗口
- **签到日志** — 记录每次签到结果，支持清理
- **结果通知** — 签到成功/失败弹出系统通知
- **后台保活** — 内附电池优化、自启动设置引导

## 技术栈

| 组件 | 说明 |
|------|------|
| Kotlin | 100% Kotlin |
| Jetpack Compose | Material3 UI |
| Room | 本地 SQLite 数据库 |
| OkHttp 4 | CAS 认证 + 签到 API |
| WorkManager | 后台定时任务调度 |
| Gson | JSON 解析 |

## 构建

Android Studio Hedgehog 或更新版本，Sync 后直接 Run。

国内用户如遇 Gradle 下载慢，已配置阿里云 / 腾讯云镜像。
